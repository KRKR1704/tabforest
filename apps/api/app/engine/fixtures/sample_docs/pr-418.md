## Description

Adds the customer token service under `src/token-service/` as an Azure Function app.

What's in here:
- `POST /token` (authorization code + PKCE → access token + refresh token)
- `POST /token/validate` for the portal middleware
- Signing key read from Key Vault via app setting reference (cached for 5 min)
- App Insights request telemetry, no token values logged

Not yet:
- `POST /token/refresh` is stubbed (returns 501)
- Session handling is still the in-memory dict in `session.py` (temporary!)
- No end-to-end test against the Fabrikam tenant (see below)

How to test locally:
```
cd src/token-service
func start
curl -X POST localhost:7071/api/token -d @samples/code_exchange.json
```
